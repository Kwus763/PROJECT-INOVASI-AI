# PROJECT-INOVASI-AI
tugas inovasi ai
Project ini bertujuan untuk membangun sistem Kecerdasan Buatan (AI) berbasis klasifikasi yang mampu memprediksi status jejak karbon individu (kategori Tinggi atau Rendah) berdasarkan 4 pola perilaku konsumsi harian, yaitu: frekuensi mandi, jarak tempuh kendaraan bulanan, jumlah pembelian baju baru, dan durasi penggunaan internet harian.

Project ini mencakup tahap Data Cleaning, Exploratory Data Analysis (EDA) dengan matriks korelasi, hingga pemodelan komparatif menggunakan dua algoritma Machine Learning: Decision Tree Classifier dan Random Forest Classifier. Berdasarkan hasil evaluasi eksperimen terbaru, model Decision Tree Classifier terbukti menghasilkan performa akurasi yang lebih tinggi dan optimal. Oleh karena itu, model Decision Tree dipilih untuk di-deploy ke dalam sistem prediksi interaktif yang dilengkapi dengan fitur interpretasi data dan rekomendasi solusi ramah lingkungan secara langsung bagi pengguna.
